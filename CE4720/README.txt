The CE4720_SimpleCPU folder contains the updated version of the simple CPU created as a final project for CE4720 at UW-Platteville. 
This program runs on the Quartus II software. There will be a Quartus II project file (CE4720_SimpleCPU.qpf), open that first. From there, you can open the top level block schematic (CE4720_SimpleCPU.bdf). 

Compile the program using the purple triangle in the toolbar. When complied, open the Waveform2.wvf file (you may need to select "Show all files (.*)"). Run this timing simulation and you will see the program run and the subsequent memory dump.
